# Process Inbox

1. List files under `00-Inbox/`; do not inspect unrelated private folders.
2. Read each candidate file and identify its topic, source, and likely note type.
3. Search the vault for duplicates or related notes before drafting anything.
4. Recommend one of: knowledge, experience, project, resource, learning, or discard/archive.
5. For each item, propose:
   - destination path,
   - concise title,
   - useful tags,
   - related notes,
   - source/provenance,
   - unresolved questions.
6. Draft new or updated files using the matching template.
7. Present a plan with exact file paths and a diff/summary.
8. Wait for explicit approval before writing, moving, or archiving files.
9. Never delete raw Inbox material. After approval, retain it or move it to an archive only if the user approves.
10. Finish by listing remaining unprocessed items.
