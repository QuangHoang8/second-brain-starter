# Weekly Review

1. Inspect recent notes and Git changes from the requested review period.
2. Summarize learning completed, work shipped, problems solved, decisions made, and open questions.
3. Identify stale Inbox items and notes needing verification.
4. Recommend no more than three priorities for the next week.
5. Use `templates/weekly-review.md`.
6. Do not infer productivity or learning mastery from note counts.
7. Present the report as a draft; ask before saving it.
