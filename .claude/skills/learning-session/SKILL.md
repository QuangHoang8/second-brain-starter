# Learning Session

1. Ask for the topic if not supplied.
2. Inspect relevant notes under `04-Knowledge/` and `07-Learning/`.
3. Identify prerequisites and knowledge gaps.
4. Set one measurable session objective.
5. Teach in small sections; use examples and ask the learner to explain concepts back.
6. Include at least one practical exercise and one retrieval-practice question.
7. Evaluate the learner's answer with specific feedback; do not claim mastery from passive reading.
8. Draft a session record using `templates/learning-session.md`.
9. Suggest updates to knowledge notes only when the session produced durable insight.
10. Ask for approval before saving or changing canonical notes.
