# Create Knowledge Note

1. Identify the concept and intended reader.
2. Search for an existing note before creating a new one.
3. Use `templates/knowledge-note.md`.
4. Explain the concept in original wording; distinguish established facts from assumptions.
5. Include a mental model, how it works, a practical example, trade-offs, common mistakes, and when to use it where relevant.
6. Cite primary sources in the Sources section. Include access dates for web resources.
7. Add meaningful wikilinks to existing notes; do not create links just to increase graph density.
8. Validate frontmatter against `90-Metadata/schemas/note.schema.json`.
9. Present the proposed diff and wait for approval before writing.
