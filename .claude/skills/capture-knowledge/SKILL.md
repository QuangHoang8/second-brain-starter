# Capture Knowledge

When the user asks to capture information:

1. Ask for clarification only if the content or intended meaning is genuinely unclear.
2. Create a dated Markdown file under `00-Inbox/quick-notes/` unless another Inbox subfolder is more suitable.
3. Use `templates/inbox-capture.md` as the structure.
4. Preserve the user's original meaning; do not add unsupported claims.
5. Add source information when provided.
6. Do not create canonical knowledge notes during capture.
7. Show the proposed file path and a short summary. The user must approve the write if approval has not already been given.
