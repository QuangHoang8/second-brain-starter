# Create Experience Note

1. Establish whether this is first-hand experience, a reported incident, or a hypothetical example.
2. Use `templates/experience-note.md`.
3. Record context, impact, symptoms, investigation, root cause, resolution, verification, and lessons learned.
4. Separate confirmed root cause from hypotheses.
5. Do not include secrets, personal data, customer data, or confidential production details.
6. Link the experience to relevant knowledge and project notes.
7. If root cause or resolution is unknown, state that clearly.
8. Show the proposed note and wait for approval before writing.
