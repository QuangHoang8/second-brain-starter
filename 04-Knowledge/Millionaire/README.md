# Millionaire Knowledge Base

Đây là knowledge layer của Millionaire Mentor.

Mỗi note nên tập trung vào một concept/nhân vật/sự kiện.

## Template tối thiểu

```yaml
---
type: knowledge
domain: millionaire
topic:
subtopic:
status: draft
---
```

## Nguyên tắc

- Một note = một đơn vị kiến thức có thể tái sử dụng.
- Link các concept liên quan bằng `[[WikiLink]]`.
- Ghi source cho factual claims quan trọng.
- Không biến knowledge note thành danh sách câu hỏi.
